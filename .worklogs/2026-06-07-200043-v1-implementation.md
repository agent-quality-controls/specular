# driftless V1 implementation

## Summary

Built the V1 Rust workspace per the lock-free plan: `lint` and `verify` library functions plus thin CLI, builtin tree/content verifiers over aqc-filetree/aqc-fs-utils, custom verifier execution with the JSON-lines evidence protocol, closure stamps, and Git diagnostics via aqc-git-helpers. The build contract passes: `scripts/spec-verify.sh` exit 0, 9/9 requirements. cargo check/clippy/fmt clean.

## Decisions made

- Hand-rolled arg parsing in main.rs (two subcommands + `--json`); clap rejected as unneeded weight.
- jsonschema with default features off (drops reqwest/TLS tree; schema is self-contained).
- sha2 added for closure stamps (RustCrypto, passes the health gate); raw-byte hashing, no canonicalization.
- Lint staging: JSON Schema violations return before serde/garde/semantic checks (a shape-invalid spec cannot be typed); semantic violations are collected exhaustively, not first-error.
- Untracked-directory handling in git diagnostics: porcelain v1 collapses `?? dir/`; files under an untracked dir are reported untracked via prefix match (found by smoke test).

## Bugs found by smoke tests (the verifier-is-not-enough lesson)

- `glob_to_re` in the bash harness escaped `.` twice ('.' was inside the first sed class AND had its own pass), so `**/*.rs` matched nothing: the content check passed vacuously on a repo with Rust files. Proven fixed by planting `#[cfg(test)]` in a scratch .rs and watching it fail.
- BSD awk treats `\b` as backspace: verify-enumerations.sh extracted empty variant sets. Fixed with `[ {]` boundary.
- Binary smoke matrix (sandbox repo): pass -> 0; violation -> 1; custom verifier unclaimed-id/silent/nonzero -> 2 with precise messages; MERGEABLE/DUPLICATE/PATH_RULE/VACUOUS lint violations; `--json` report shape; stamps and source labels correct.
