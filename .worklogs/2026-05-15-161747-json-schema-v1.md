Summary
- Set strict JSON plus generated JSON Schema plus Rust semantic validation as the V1 source-format decision.
- Removed CUE, Pkl, HCL, Dhall, JSONC, Jsonnet, and Starlark from active V1 source-format scope.

Decisions made
- Rust types are the source of truth for the spec shape.
- `schemars` generates the user-facing JSON Schema from Rust types.
- `jsonschema` validates source JSON against the generated schema.
- Serde decodes source JSON into Rust types.
- Rust semantic validation handles cross-field and domain rules.
- Comments are not supported in V1; explanations use explicit fields such as `reason`.
- JSON source shape should avoid dynamic object maps where duplicate keys could hide data.
