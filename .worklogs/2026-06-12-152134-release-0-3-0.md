# Release 0.3.0 bump

## Summary

Bumped Specular from `0.2.0` to `0.3.0` for the v2 spec format release.
Updated the lockfile, help/report examples, the historical plan report example,
and verify fixture goldens that include `specular_version`.

## Decisions made

- Used `0.3.0` because version 2 removes top-level `verifiers` and changes the
  public spec format.
- Approved fixture drift only after confirming the verify suite changed only
  `specular_version`.
- Left dependency versions alone; the remaining `0.2.0` in `Cargo.lock` belongs
  to a transitive dependency.
